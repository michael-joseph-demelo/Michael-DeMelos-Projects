# Fitness Application
A mobile fitness application developed as a fourth-year group project for my Mobile Application Development class.

## Overview
The goal of this project was to create a functional and useful mobile application while working as a group. Our group developed a fitness and wellness app designed to help users build healthy habits, track their progress, and stay motivated.

## My Role
I was responsible for developing the Personalized Music and Memory sections of the application.

- Developed the Personalized Music section
- Created functionality for users to select their music preferences
- Implemented music recommendations based on user preferences
- Developed the Memory section for saving and viewing pictures
- Worked with the rest of the group to integrate my sections into the overall application
- Tested and refined my features to ensure they worked correctly

## Features
The application included several features designed to support the user's fitness and wellness goals:

- User sign-up and profile information
- Daily checklist and task tracking
- Goal setting and progress tracking
- Sleep tracking
- Mindfulness break timer and notifications
- Personalized music recommendations
- Picture memory section
- Travel and activity planning
- Multiple pages connected through a central home screen
- Notifications and navigation between app features
- Project Context
- This application was created as part of my fourth-year Mobile Application Development class. The project focused on applying mobile development concepts while working collaboratively as a group to design, develop, and integrate multiple features into one application.
